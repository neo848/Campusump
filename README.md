# Campus Connecte

- **Windows** : ouvrir `windows/`, puis double-cliquer sur `INSTALLER.bat`.
- **Linux (NetworkManager)** : ouvrir `linux/`, puis executer `sh INSTALLER.sh` sans sudo.
  Ouvrir un nouveau terminal et taper **campuse** depuis n'importe quel dossier.

Les assistants preservent une connexion fonctionnelle et demandent la zone du campus
avant les essais d'IP statique. Les changements IP de la session sont nettoyes a la sortie.
Voir [le guide Linux](linux/README.md) pour les prerequis et les limites.
